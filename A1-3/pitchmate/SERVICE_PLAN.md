# 서비스 기획서 - PitchMate

## 1. 서비스 개요
- 서비스명: PitchMate
- 목적: 발표 시작 멘트를 생각하기 어려운 사용자가 짧은 입력만으로 발표 오프닝과 흐름을 얻도록 돕는다.
- 타겟 사용자: 발표 과제가 잦은 대학생 및 초보 발표자

## 2. 페이지/섹션 구성
1. 홈: 서비스 목적과 핵심 가치 소개
2. AI 생성: 발표 주제/대상/분위기를 입력하고 AI 결과 확인
3. 사용법: 3단계 이용 방법 안내
- 상단 메뉴를 누르면 각 섹션으로 이동한다.

## 3. 핵심 기능
- 발표 주제 입력
- 발표 대상 입력
- 분위기 선택
- Gemini API 기반 발표 시작 멘트 및 3단계 발표 흐름 생성
- 모바일 반응형 표시

## 4. AI 기능 설계
- 입력: 발표 주제, 발표 대상, 원하는 분위기
- 출력: 시작 멘트, 발표 흐름 3개, 마무리 연결 문장
- 사용자 가치: 발표 첫 문장을 빠르게 구성하고 발표 전체 흐름의 초안을 얻을 수 있다.

## 5. 실패 처리 기준
- 빈 입력: 필수 항목 입력 안내
- API 오류: 잠시 후 재시도 안내
- 지연/타임아웃: 응답 지연 안내
