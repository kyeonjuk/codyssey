# My Prompt Manager

Python 기본 문법을 활용하여 만든 콘솔 기반 AI 프롬프트 관리 프로그램입니다.

## 실행 방법

```bash
python3.12 main.py
```

### 주요 기능
- 프롬프트 추가
- 전체 프롬프트 목록
- 카테고리별 조회
- 제목/내용 키워드 검색
- 프롬프트 상세 보기
- 즐겨찾기 추가 및 해제
- 즐겨찾기 목록

### 카테고리
- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타


### 데이터 구조

프롬프트 데이터는 Python의 리스트와 딕셔너리를 사용합니다.

각 프롬프트는 다음 정보를 포함합니다.

- 제목
- 내용
- 카테고리
- 즐겨찾기 여부
